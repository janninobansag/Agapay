# Delivery roadmap

## Milestone 1: Application foundation

- [x] Next.js, TypeScript, Tailwind CSS, and ESLint
- [x] Responsive visual system and reusable layout
- [x] Marketing, authentication, dashboard, reports, and submission routes
- [x] Product and development documentation
- [x] Automated checks in GitHub Actions

## Milestone 2: Data foundation

- [x] Design the PostgreSQL schema
- [x] Configure Prisma and database migrations
- [x] Seed realistic demonstration data
- [x] Replace sample report data with server queries
- [x] Add input validation with Zod
- [x] Apply the migration and seed to a reachable PostgreSQL database

## Milestone 3: Identity and permissions

- [x] Configure Auth.js
- [x] Add resident, staff, and administrator roles
- [x] Protect routes and establish server-action authorization guards
- [x] Test resource-level authorization policies

## Milestone 4: Reporting workflow

- [x] Persist new reports and drafts
- [x] Upload and optimize evidence images
- [x] Add report editing and cancellation rules
- [x] Build staff verification, assignment, and resolution tools
- [x] Record an immutable audit trail

## Milestone 5: Maps and notifications

- [x] Add MapLibre and OpenStreetMap
- [x] Geocode and validate report locations
- [x] Add in-app notification delivery
- [x] Add email notification templates

## Milestone 6: Portfolio release

- [ ] Unit, integration, and end-to-end coverage
- [ ] Accessibility and performance audit
- [ ] Container and production deployment configuration
- [ ] Seeded demo accounts and guided product tour
- [ ] Architecture diagram, screenshots, and case study
